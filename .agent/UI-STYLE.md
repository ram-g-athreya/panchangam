# UI-STYLE.md

Specifies the overall UI CSS Styling for the app

## Font Conventions

- Load the `samarkan` font globally in `src/styles/index.css` to be used app wide

## Color Conventions

The app broadly has two themes, a sepia based light theme and a dark theme. The themes need to be defined at the top level and it should be easy to programmatically swich between light and dark themes across the app

### Light Theme (Sepia)

- Main Background: #F4EBD0
- Secondary Background: #E6D5B8
- Primary Text: #3C2A21
- Secondary Text: #634832
- Accent: #B68D40

# Dark Theme

- Main Background: #1A120B
- Secondary Background: #2E1E14
- Primary Text: #D5C4a1
- Secondary Text: #A88d70
- Accent: #D4A373
